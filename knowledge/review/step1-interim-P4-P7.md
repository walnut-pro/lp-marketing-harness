## 1. 重要な発見①：出典番号は回答ごとに変わる → S0 では解決できない

同じ「4コマ漫画」の発言が、回答によって source 8 / 9 / 10 / 11 / 12 と別々の番号で引用されている。
番号は回答ごとの通し番号であり、あとから対応表（S0）を取っても過去の回答には当てはめられない。

**対応**: S0 は取り下げ。代わりに **V1（動画別の索引）** を取得し、責任者が各原則の引用文と照合して出典動画を確定する。
（コンテナから YouTube への接続は組織のネットワーク設定で遮断されており、責任者が字幕を直接取得することはできない）

## 2. 重要な発見②：RAG の知識量は「約26の考え方」で、LP制作の全工程はカバーしていない

71件のうち大半は同じ考え方の言い換えだった（例：4コマ漫画は4回、チャットボットは5回、「1つに絞る」は3回登場）。
各カテゴリで件数を求めたため、Gemini が同じ話を別カテゴリで繰り返したと考えられる。

ソースに**登場しない**、一般的なLP制作では必要な要素:

| 領域 | ソースに無い要素 |
|---|---|
| 構成 | お客様の声・口コミ、FAQ、返金保証、LPの長さの目安 |
| CTA | ボタンの文言・色・位置・回数 |
| フォーム | 入力項目数の目安、エラー表示 |
| デザイン | フォント・配色・画像の仕様（DES-009 は Gemini 自身が「出典なし」） |
| 法令 | 特定商取引法（定期購入の最終確認画面の表示義務）、打消し表示、ビフォーアフター |
| 運用 | 勝敗判定の統計ルール（必要サンプル数） |

P8・P9 で一部埋まる可能性はあるが、**「すべての作業をAI自動化」には RAG だけでは足りない**見込みが高い。
→ 監査人に判断してほしい論点（下記「決定事項 D1」）。

## 3. 統合の方針

| 判断 | 内容 |
|---|---|
| 統合 | 同じ考え方は1原則にまとめ、`merged_from` に元IDを全て残す |
| 一般化しすぎの修正 | チャットボット（OFR-CHATBOT）：ソースは競合 DUO の1事例なのに Gemini が「常に」と一般化 → optional に格下げ。4コマ漫画も予約型サービスの1事例 → optional |
| 合成の格下げ | STRUC-TEMPLATE：ソースが明示した構成ではなく Gemini の合成 → confidence: low。実際の構成は競合LPの分析で決める |
| 参考に分類 | 内製化、市場参入のタイミング、複数ブランド、SEO記事、広告クリエイティブの入れ替え |
| 却下候補 | DES-009（出典なし） |
| 自動採点の方法 | 全原則に `check`（自動採点の方法）を責任者が追加。ソース由来ではないことを明記 |
| RAG外の注意書き | 著作権（情報の「整理」は要約・再構成に限る）、比較広告、特商法を `notes` に「RAG外」と明記して追加 |
