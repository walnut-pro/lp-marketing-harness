# ADR-0002: Gemini Notebook の回答を信頼済みデータとして扱う

- ステータス: **決定**（監査人の判断）
- 日付: 2026-09-26

## 背景

Step 1c として、原則の引用をYouTube字幕の原文と照合する計画だった（roadmap v2）。
しかし実行環境のネットワーク方針で YouTube に接続できず、設定変更も難しい。

## 決定

- Gemini Notebook の回答（`knowledge/raw/P1〜P9`、以後の追加質問を含む）を**信頼できるデータ**として扱い、字幕原文との照合（Step 1c）は行わない。
- 原則の出典は `merged_from`（raw の ID）で辿る。これにより「原則 → Gemini の回答」までのトレーサビリティは保たれる。
- Gemini の `source` 番号と `timestamp` は、動画を特定できず推定値でもあるため使わない。
- 必要に応じて Gemini への追加質問を行ってよい。

## 信頼の範囲（責任者の運用）

「信頼する」は、回答の内容を事実として採用するという意味であり、次の修正は引き続き行う。

- **回答の内部で矛盾・混入が明らかなもの**は除外する（例：RISK-007 の薬機法の根拠に、脱税の話の発言が混入）。除外理由は `audit_notes` に残す。
- **Gemini の一般化・合成**（1事例を「常に」とする、構成テンプレートの合成）は、内容は採用しつつ `confidence` と `scope` で重み付けする。

## 影響

- roadmap の Step 1c（出典の検証）は省略。Step 1 の合格基準から「引用が検証済み」を外す。
- footguns F-02, F-03, F-07 は「受容」とする。
- 残るリスク: 引用の誤りや混入を完全には除けない。法令に関わる判断は、公開前の人の承認（憲章）で担保する。
