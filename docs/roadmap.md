## 作業規則（振り返りから）

1. **パイロット規則**: 新しいプロンプト・ツール・手順は1件で試し、出力形式を検証してから本番に回す（F-01）
2. **Gemini への問い合わせ規則**: 件数の下限を課さない／他カテゴリとの重複を禁止／無ければ無いと答えさせる／終端マーカーで件数を照合（F-04, F-05）
3. **引用の扱い**: 字幕原文で照合できるまで「未検証」（F-03）
4. **ゲート規則**: 未承認のステップは「準備（未承認）」と明記した作業に限る（F-12）
5. **文書更新の確認**: 機械的に書き換えたら grep で結果を確認してからコミット（F-13）
